# Деплой сайта IUVENTA на хостинг

Этот репозиторий хранит **только кастомную тему** (`wp-content/themes/iuventa`)
и скрипты разработки. Ядро WordPress, `wp-config.php` и базу данных намеренно
**не** держат в git — это стандартная практика (ядро WP занимает ~100 МБ,
обновляется отдельно и не должно лежать в репозитории проекта).

Локально для разработки используется **SQLite** (быстро, без отдельной СУБД).
На обычном хостинге используется **MySQL** — поэтому для заливки нужно собрать
полноценный стандартный пакет WordPress.

## 1. Собрать готовый пакет

```bash
bin/setup.sh        # если ещё не запускали — скачает ядро WP локально
bin/build-dist.sh   # соберёт полный сайт
```

После сборки в папке `dist/` появятся:

| Файл | Назначение |
| --- | --- |
| `dist/iuventa-site/` | Полная стандартная установка WordPress (ядро в корне + тема `iuventa`), настроенная под MySQL |
| `dist/iuventa-site.zip` | То же самое, упаковано для загрузки на хостинг |
| `dist/iuventa-content.xml` | Экспорт контента (WXR) — **по желанию**, для переноса локально отредактированного контента |

Структура `dist/iuventa-site/` — обычный WordPress (`wp-admin/`,
`wp-includes/`, `wp-content/`, `index.php`, `wp-config.php` …), который
загружается на любой PHP/MySQL-хостинг.

## 2. Загрузить на хостинг

1. Распакуйте `iuventa-site.zip` и загрузите его содержимое в корень сайта
   (обычно `public_html/` или `www/`) по FTP/SFTP или через файловый менеджер
   панели хостинга.
2. В панели хостинга создайте **базу данных MySQL** и пользователя, запомните:
   имя БД, имя пользователя, пароль, хост (обычно `localhost`).

## 3. Прописать доступ к базе

Откройте `wp-config.php` в корне сайта и подставьте свои данные:

```php
define( 'DB_NAME',     'имя_базы' );
define( 'DB_USER',     'пользователь' );
define( 'DB_PASSWORD', 'пароль' );          // замените ЗАМЕНИТЕ_ПАРОЛЬ
define( 'DB_HOST',     'localhost' );
```

Соль-ключи (`AUTH_KEY` и т.д.) уже сгенерированы скриптом сборки — менять не нужно.

## 4. Установить WordPress

Откройте сайт в браузере — запустится стандартный мастер установки WordPress
(«знаменитая установка за 5 минут»): задайте название сайта, логин и пароль
администратора.

## 5. Включить тему

1. Войдите в админку: `https://ваш-домен/wp-admin/`.
2. **Внешний вид → Темы** → активируйте тему **IUVENTA**.
3. При активации тема **автоматически создаёт** 10 процедур и 6 косметологов
   (как на текущем сайте). Их сразу можно редактировать в разделах
   «Процедуры» и «Косметологи».
4. Тексты главной страницы — **Внешний вид → Настроить → «Главная страница
   (Ювента)»**.

## 6. (Опционально) Перенести локально отредактированный контент

Если вы редактировали контент локально и хотите перенести именно его:

1. **Не** полагайтесь на авто-наполнение (чтобы не было дублей): на свежем
   хостинге после установки сразу зайдите в **Инструменты → Импорт →
   WordPress**, установите импортер и загрузите `dist/iuventa-content.xml`.
2. Если процедуры/косметологи уже создались автоматически — удалите дубли или
   импортируйте на чистую базу до активации темы.

## Требования хостинга

- PHP 7.4+ (рекомендуется 8.x)
- MySQL 5.7+ / MariaDB 10.3+
- Стандартные расширения PHP для WordPress (`mysqli`, `mbstring`, `gd`, `curl`, `xml`)

## Частые вопросы

- **Почему в репозитории нет `wp-admin`/`wp-includes`?** Это ядро WordPress; его
  не версионируют. Скрипт `bin/build-dist.sh` добавляет его в пакет для заливки.
- **Можно ли загрузить SQLite-версию?** На большинстве хостингов — нет, они
  рассчитаны на MySQL. Поэтому пакет собирается под MySQL. SQLite используется
  только для локальной разработки.
